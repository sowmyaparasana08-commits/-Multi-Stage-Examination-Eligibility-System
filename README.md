## Case Study: Multi-Stage Examination Eligibility System

### Problem Statement
Evaluate whether students qualify to sit for a final examination based on four criteria: minimum attendance percentage, laboratory completion, internal assessment marks, and fee clearance. Instead of stopping at the first failure, the system reports every unmet requirement along with exact shortfalls where applicable.

### Key Features Implemented
* **Four-Stage Validation:** Checks attendance, lab work completion, internal assessment score, and fee clearance status independently.
* **Complete Deficiency Reporting:** Collects and displays all unmet conditions for a student rather than short-circuiting on the first failure.
* **Batch & Single-Student Support:** Evaluates individual student dictionaries or a full list of student records.

```bash
python exam_eligibility_system.py
